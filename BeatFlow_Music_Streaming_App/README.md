# BeatFlow Music Streaming App
Academic front-end project using only HTML, CSS and JavaScript.

Features:
- Admin and User modules
- Signup/Login with Local Storage
- Search
- Favorites
- Recently played
- Admin add/delete songs
- JavaScript navigation
- CSS Grid/Flexbox responsive UI
